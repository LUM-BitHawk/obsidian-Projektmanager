## Kurzanleitung: Installation unter Windows

![Setup-Assistent](screenshots/Setup-Assistent_Vorschau.png)

1. **Willkommen:** `Obsidian-Agent-Setup-2.0.0.exe` starten und mit **Weiter** bestätigen. Administratorrechte sind nicht nötig.
   Meldet Windows *Der Computer wurde durch Windows geschützt*, auf **Weitere Informationen** und dann **Trotzdem ausführen** klicken.
2. **Zielverzeichnis:** Vorschlag `%LOCALAPPDATA%\Programs\Obsidian-Agent` übernehmen oder mit **Durchsuchen** ändern. Optionen wählen: Start bei der Anmeldung, Verknüpfung im Startmenü und auf dem Desktop.
3. **Obsidian-Vault:** den Ordner deines Vaults wählen. Bestehende Notizen werden nie gelöscht oder umbenannt. Alternativ *Später in den Einstellungen festlegen*.
4. **Installieren:** Programm und Python-Umgebung werden eingerichtet. Fehlt Python, wird es automatisch installiert.
5. **Fertigstellen:** *Obsidian-Agent öffnen* anhaken. Die Oberfläche öffnet sich im Browser unter `http://127.0.0.1:5055`.

**macOS:** `Obsidian-Agent-2.0.0.pkg` per Rechtsklick > **Öffnen** starten, den Schritten folgen und am Ende den Vault wählen. Die App liegt danach unter *Programme*.

Ausführlich: Abschnitte 1 und 2 der jeweiligen Anleitung.
